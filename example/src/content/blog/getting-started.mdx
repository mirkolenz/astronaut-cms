# Getting Started Here!

Welcome to Astronaut CMS! This post demonstrates MDX components.

![Test](../../assets/ethan-teng-km7EbYvkegE-unsplash.jpg)

<Alert type="info">
  This is an informational alert rendered as a structured block in the CMS editor.
</Alert>

## Features

Here are some of the key features:

- Structured block editing for MDX
- Live preview with remark/rehype plugins
- Schema-driven prop forms

<Callout title="Pro Tip">
  You can define your own components in `cms.config.ts` and they will appear as blocks in the
  editor.
</Callout>

<Tabs>
  <Tab label="Installation">Run `npm install astronaut-cms` to get started.</Tab>
  <Tab label="Configuration">Create a `cms.config.ts` file in your `src/` directory.</Tab>
</Tabs>
