Astronaut CMS requires Astro 7 and React 19.
Install the CMS package along with its peer dependencies.

<Tabs>
  <TabItem label="npm">```sh npm install astronaut-cms @astrojs/react react react-dom ```</TabItem>
  <TabItem label="pnpm">```sh pnpm add astronaut-cms @astrojs/react react react-dom ```</TabItem>
</Tabs>

<Aside type="tip">
  If you want to use MDX content (recommended for block components), also install `@astrojs/mdx`:

```sh
npm install @astrojs/mdx
```

</Aside>

## Peer Dependencies

| Package          | Version | Purpose                               |
| ---------------- | ------- | ------------------------------------- |
| `astro`          | `^7`    | Astro framework                       |
| `@astrojs/react` | `^6`    | React integration for the admin panel |
| `react`          | `^19`   | React runtime                         |
| `react-dom`      | `^19`   | React DOM renderer                    |

## Optional Dependencies

| Package        | Version | Purpose                          |
| -------------- | ------- | -------------------------------- |
| `@astrojs/mdx` | `^5`    | MDX support for block components |
