Astronaut CMS requires Astro v6 or later and React 19.
Install the CMS package along with its peer dependencies.

<Tabs>
  <TabItem label="npm">
    ```sh
    npm install astronaut-cms @astrojs/react react react-dom
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```sh
    pnpm add astronaut-cms @astrojs/react react react-dom
    ```
  </TabItem>
</Tabs>

<Aside type="tip">
  If you want to use MDX content (recommended for block components), also install `@astrojs/mdx`:

  ```sh
  npm install @astrojs/mdx
  ```
</Aside>

## Peer Dependencies

| Package | Version | Purpose |
|---|---|---|
| `astro` | `^6` | Astro framework |
| `@astrojs/react` | `^5` | React integration for the admin panel |
| `react` | `^19` | React runtime |
| `react-dom` | `^19` | React DOM renderer |

## Optional Dependencies

| Package | Version | Purpose |
|---|---|---|
| `@astrojs/mdx` | `^5` | MDX support for block components |
