The CMS integration is added to your `astro.config.ts` file.
It accepts an optional configuration object to customize its behavior.

## Basic Setup

```ts title="astro.config.ts"
import { defineConfig } from "astro/config";
import mdx from "@astrojs/mdx";
import react from "@astrojs/react";
import cms from "astronaut-cms";

export default defineConfig({
  integrations: [mdx(), react(), cms()],
});
```

<Aside type="caution">
  The `react()` integration must be included for the admin panel to work. The `mdx()` integration is
  needed if you use MDX block components.
</Aside>

## Configuration Options

Pass options to `cms()` to customize the integration:

```ts title="astro.config.ts"
cms({
  mountPoint: "/admin",
  locale: "en",
  storage: { type: "local" },
  media: {
    directory: "src/assets",
    maxFileSize: 10_000_000,
  },
});
```

### `mountPoint`

- **Type:** `string`
- **Default:** `"/admin"`

The URL path where the admin panel is served.

`@astrojs/sitemap` lists every page route, the admin included, and another integration cannot take one out.
Exclude it with the sitemap's `filter`.
The integration warns when a built sitemap still lists the admin, provided `sitemap()` comes before `cms()` in `integrations`, since it reads the files the sitemap wrote.

```ts title="astro.config.ts"
sitemap({ filter: (page) => !new URL(page).pathname.startsWith("/admin") });
```

### `config`

- **Type:** `string`
- **Default:** auto-discovered from `src/cms.config.{ts,mts,js,mjs}`

Path to the CMS config file, relative to the project root.

### `locale`

- **Type:** `"en" | "de"`
- **Default:** `"en"`

Default language for the admin panel UI.
Editors can change it from the header, and their choice is remembered.

### `i18n`

- **Type:** `{ locales?: string[]; defaultLocale?: string } | false`
- **Default:** inherited from the site's own `i18n` in `astro.config.ts`

Content languages.
Set it to override the site's languages, or to `false` to keep the admin language-agnostic.
See the [Multilingual Content](../multilingual-content/) guide for details.

### `storage`

- **Type:** `StorageConfig`
- **Default:** `{ type: "local" }`

Storage backend configuration.
See the [Storage Backends](../storage-backends/) guide for details.

### `media`

- **Type:** `MediaConfig`
- **Default:** `{ directory: "src/assets" }`

Media library configuration.
See the [Media Library](../media-library/) guide for details.
